## Descripción del Proyecto
Sistema PETI avanzado para el análisis estratégico de Unidades Estratégicas de Negocio (UEN), incorporando evaluación de ventas, análisis de mercado, competencia directa y generación automática de matriz BCG.

---

## Mejora 1: Análisis de Portafolio y Ventas

Se implementó un módulo que permite registrar ingresos por UEN y calcular automáticamente:

- Porcentaje de participación de cada unidad
- Total de ventas
- Peso estratégico de cada servicio
